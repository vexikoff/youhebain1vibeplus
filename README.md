# Youhe Bain 1: Others' Circumstances Plus

Консольный текстовый триллер о скаме, паранойе, бытовых заботах и компаниях,
которые почему-то считают ваш кошелёк частью своей экосистемы.

> Платформа: Windows · Язык: Python 3.14+ · Статус: Beta

## Об игре

Вы — обычный человек в мире странных звонков, абсурдных корпораций и
предложений, от которых юридически нельзя отказаться. Зарабатывайте очки,
принимайте решения и выясните, чем закончится знакомство с загадочным Толей.

В игре есть бытовые занятия, магазин, случайные звонки, рыбалка, проверка
реакции и несколько сюжетных финалов. DLC **Vibe Plus** добавляет отдельное
расследование о подписке, которую вы почти оформили, ничего не нажимая:

- 18 игровых этапов — от первого письма до закрытия досье;
- экзамен по договору, сбор улик, побочное дело, допрос представителя, подготовка слушания и второе заседание;
- выборы о публикации доказательств, сотрудниках, банке и суде;
- десять возможных финалов.

Vibe Plus открывается с третьего игрового дня. Прогресс дополнения сохраняется
в `save.json` вместе с основным прохождением.

## Установка и запуск

### Готовая сборка

Скачайте архив игры со страницы
[Releases](https://github.com/vexikoff/youhebain1vibeplus/releases), распакуйте его
в отдельную папку и запустите EXE. Не перемещайте отдельные WAV-файлы из папки
сборки: они нужны музыке и звуковым эффектам.

### Запуск из исходников

Нужны Windows и Python 3.14 или новее.

```powershell
git clone https://github.com/vexikoff/youhebain1vibeplus.git
cd youhebain1plus
python -m pip install -r requirements.txt
python main.py
```

Для подробной инструкции по PyInstaller, иконке и сборке EXE см.
[BUILD.md](BUILD.md).

## Управление

| Клавиша | Действие |
| --- | --- |
| `1`–`9` | Выбрать действие в главном меню |
| `0` | Позвонить Толе, если действие доступно |
| `Q` | Открыть магазин |
| `E` | Заглянуть в рюкзак |
| `H` | Написать в поддержку |
| `V` | Открыть условия Vibe Plus |
| `Enter` | Подтвердить выбор или действовать в мини-игре |

## Сохранения

Игра автоматически сохраняет прогресс в `save.json` в текущей рабочей папке.
Чтобы сделать резервную копию, скопируйте этот файл. Для продолжения прохождения
не удаляйте его.
