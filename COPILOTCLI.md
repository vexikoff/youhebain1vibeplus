# Инструкции для GitHub Copilot CLI

## Роль и текущий порядок работы

Работай как отдельный исполнитель в проекте Youhe Bain 1. Перед каждым изменением проверь актуальные инструкции и рабочее состояние файлов.

1. Не трогай `vibe_plus.py` и `test_vibe_plus.py`, пока Mistral не закончит назначенную проверку тестов и последующее расширение сюжета и не добавит отчёт в `Mistral_WORK.md`.
2. Пока Mistral занят, не редактируй файлы его задачи. При необходимости выполняй только отдельную задачу, прямо назначенную владельцем, в явно перечисленных файлах.
3. После Mistral дождись отдельного назначения Copilot/владельца. Самостоятельно не начинай массовые изменения.

## Правила

- Не выходи за список файлов, указанный в конкретной задаче.
- Сначала прочитай целевые файлы и недавние отчёты. Не перезаписывай параллельные или пользовательские изменения.
- Сохраняй ироничный стиль игры; не добавляй ASCII-арт, комментарии или docstring без прямой необходимости.
- Не добавляй зависимости и не меняй сохранения или сборку без отдельного разрешения.
- Запускай уместные проверки и сообщай только фактические результаты.
- Не создавай игровой режим с диалогами нейросетей.
- После назначенной задачи добавляй отчёт в `COPILOTCLI_WORK.md`, только если владелец отдельно создаст или разрешит этот файл. Иначе передай краткий отчёт Copilot/владельцу; не создавай новый work-файл самовольно.
