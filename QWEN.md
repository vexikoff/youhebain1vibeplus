# Задание для Qwen

## Роль и очередь

Пиши и интегрируй игровой код. Начинай только после завершения и коммита ChatGPT, Mistral и GLM; изучи их work-отчёты и убедись, что `main.py` свободен от незакоммиченных чужих правок. До этого жди.

## Задача — система достижений и статистики прохождения

Разрешены новые файлы `achievements.py`, `test_achievements.py` и интеграционные изменения `main.py`.

Добавь в игру полезную систему достижений и статистики:

- Создай не менее 12 достижений по разнообразным фактам прохождения: дни выживания, рыбалка/бытовые занятия, ключевые решения основного сюжета и результаты Vibe Plus. Не создавай достижение за действия, которые невозможно отследить по текущему коду.
- Для каждого достижения задай стабильный ID, короткое ироничное русское название, описание и явное условие разблокировки.
- Показывай список достижений из отдельной команды/клавиши меню с состоянием «получено/ещё нет» и подходящей статистикой; просмотр не должен тратить ход.
- Храни прогресс и разблокировки в существующем `save.json`; старые сохранения без этих полей должны безопасно нормализоваться.
- Вынеси определения, проверку условий, нормализацию и обновление статистики в чистый модуль `achievements.py`; подключи его к актуальным игровым событиям в `main.py`.
- Добавь тесты на все типы условий, сохранение/загрузку полей, неизвестные ID и старые сохранения.

Не делай достижения зависимыми от необязательного DLC, чтобы их нельзя было получить в основной игре; DLC-достижения могут быть дополнительными. Не меняй баланс очков или условия существующих сюжетных финалов. Без новых зависимостей, ASCII-арта, комментариев и docstring.

Проверки:

```powershell
python -m unittest -q test_achievements test_call_events test_vibe_plus
python -m py_compile main.py achievements.py test_achievements.py
```

Добавь отчёт в конец `QWEN_WORK.md`, затем создай отдельный коммит только своих файлов с Co-authored-by trailer Copilot. Push — только по запросу владельца.
